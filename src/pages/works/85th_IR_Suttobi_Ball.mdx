# **はじめに**

この記事は参加型工作企画で作成する、すっとびボールについてのものです。

おかしな名前だとお思いになるかもしれませんが、別名に多段式垂直衝突球だったり、ガリレオ砲だったりの名前がついています。かなり面白いおもちゃで、物理学的な説明もあるので、ぜひお楽しみください。

# **概要**

今回制作するのは3段のすっとびボールです。

竹串と繋がった大きなスーパーボール、中心を貫通している小さなスーパーボール、そして高く高く飛んでいくピンポン玉の3つで構成されます。

今から制作方法を紹介します。機械などが必要で難易度の高いところは、すでに部員たちが行っているので、ぜひ遠慮なくご参加ください。

## 材料の用意

- 竹串

- 大きなスーパーボール

- 小さなスーパーボール

- ピンポン玉

## 制作手順

大きなスーパーボールに竹串を突き刺す。

穴を開けてあるので、そこに中心へ向かってまっすぐ刺してください。

<Warn>誤って手を怪我しないよう、十分注意してください。</Warn>

ピンポン玉に穴を開ける。

すでに開けてあります。

> **逸般**の**誤**家庭で作成される場合は、どこにでもあるボール盤で加工を行なってください。

<Warn>今回は治具となる塩ビパイプを用意していますので、部員の指示の通りに作業をお願いします。</Warn>

大きいスーパーボール、小さいスーパーボール、ピンポン玉の順で通す。

適切な順番で通しましょう。

## 完成！

まっすぐ落とすのがコツです！かなり高く飛ぶので、無くさないようにお気をつけください。

# **解説**

簡単な解説を行いますので、詳しい内容や関連事項などはぜひWikipediaなどからご覧ください。


https://ja.wikipedia.org/wiki/すっとびボール

今回はボール2段の場合についてご説明いたします。

まず大きなボールの質量をm1、小ボールの質量をm2、ボールたちが床に衝突する直前の速度をv0、衝突後の大ボールの速度をv’1、大ボールと床の反発係数をe0とします。

反発係数は0から1までの数値で、大きい方がよく反発します。

ここで以下の関係が成り立ちます。
```
v’1 = -e0 × v0
```
次に衝突後の大ボールと速度v0で落下する小ボールが衝突します。

衝突後の大ボールの速度をv1、小ボールの速度をv2とします。

運動量保存の法則から以下の関係が成り立ちます。
```
-m1v’1 - m2v0 = m1v1 + m2v2
```
また、大ボールと小ボールの反発係数をe1 として、
```
e1 = -(v1 - v2) / (-v’1 - (-v0))
```
v1とv2について、
```
v1 = (m1 - (e0e1 + e0 + e1)m2 / m1 + m2) * v0

v2 = ((e0e1 + e0 + e1)m1 -m2 / m1 + m2) * v0
```
ここで、全て完全弾性衝突(同じ速度で跳ね返る)という理想的な状態と仮定すると、e0 = e1 = 1となって、以下の式となります。
```
v1 = ((m1 - 3m2) / (m1 + m2)) * v0

v2 = ((3m1 - m2) / (m1 + m2)) * v0
```
ここで、m1 = 3m2、つまり大ボールの質量が小ボールの質量が3倍の時、以下が成り立ちます。
```
v1 = 0, v2 = 2v0
```
つまり、大ボールが小ボールの3倍の質量の時、上にある小ボールは2倍の速さで跳ね上がります。

ここで空気抵抗などを無視し保存力のみ働くとすると、小ボールは落下開始位置の4倍まで飛び上がります。

今回は3個のボールがあるので、もう少し複雑になりますが、基本的な原理は変わりません。
