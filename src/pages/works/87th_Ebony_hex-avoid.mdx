# Hex Avoid

**87期 EbonySerpent**

## はじめに

特殊な座標軸上で弾を避けるゲームを作りました。

## 概要

六角形のマスが敷き詰められたフィールドの中を自機で動き回り、四方八方から飛んでくる弾や、時限式に爆発する氷の爆弾を避け続けるアクションゲームです。

ただ避けるだけでなく、Shiftキーでシールドを展開すると、隣接マスに来た弾を防いで割ることができ、シールドはスタミナ制になっていて使いすぎると展開できなくなります。フィールド上にはスコアタイル（触るとポイント加算）やハートタイル（触るとライフ回復）もランダムに出現し、これを取りに行くかリスクを避けて守りに徹するか、といった駆け引きも生まれます。

またゲームモードとして、通常プレイの他にチュートリアルモードとキーコンフィグ画面を用意しました。チュートリアルは「移動」「シールド」「弾避け」「氷爆弾」の4ステップに分かれていて、それぞれクリア条件を満たすと自動で次のステップに進み、ゲームオーバーにならない安全な環境で操作を学べるようになっています。

## 操作方法

### タイトル画面

- `Enter` / `Space`：ゲーム開始
- `T`：チュートリアル
- `S`：キー設定

### プレイ中

- 移動キー（既定は `W` / `E` / `D` / `S` / `Q` / `A`）：6方向移動
- `Shift`：シールド展開

### 設定画面

- 変更したい方向のキーを押す → 新しいキーを押す
- `Esc` / `BackSpace`：取り消し
- `Enter` / `Esc`：タイトルへ戻る

## 解説

このゲームで一番苦労したのは、六角形グリッド特有の座標計算です。四角いマスと違って六角形は「軸座標（axial coordinate）」という特殊な座標系で管理する必要があり、隣接マスの判定や画面上のピクセル位置への変換、範囲内かどうかの判定など、あらゆる処理でこの座標系を意識しなければなりませんでした。

次に苦労したのは、弾や氷爆弾の「予告→発生」という2段階の演出です。弾は出現直後は警告表示だけを行い、少し間を置いてから実際に飛び始めます。氷爆弾も同様に、警告フェーズを経てから爆発判定を行い、爆発後は隣接マスにも判定を広げています。理不尽な当たり判定にならないよう、プレイヤーに「来るぞ」と分かる猶予を必ず挟む設計にしました。

さらに、キーコンフィグ機能の実装も想定より複雑でした。単にキーを差し替えるだけでなく、既に他の方向に割り当て済みのキーを選んだ場合は自動的に入れ替える処理や、設定中にEscでキャンセルしたときに元のキーへ戻す処理など、細かい例外処理を積み重ねる必要がありました。

演出面では、プレイヤーや弾の軌跡に残像エフェクトを付けたり、六角形のマスが弾性のあるアニメーションで展開・収縮する仕組みを作ったりと、見た目の気持ちよさにもこだわりました。単純なルールのゲームですが、駆け引きの部分と演出の部分、両方に工夫を詰め込んだつもりです。
