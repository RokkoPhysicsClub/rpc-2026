# *はじめに*

僕は今年、Mazeというゲームを作りました。

Mazeは名前の通り迷路を解くゲームです。

Mazeでは穴掘り方という迷路を作成するアルゴリズムの1つを使って迷路を生成します。

# *穴掘り方*

1. まずスタート地点を決めて、そこに1マスの道を作る

2. ランダムな方向に2マスの道を作る

3. 2 を繰り返し、行き止まりについたら2マス引き返して別の方向に道を作る

4. 2と3を繰り返して道を作れるところが無くなったらゴールを設定して迷路を完成させる。

# *ゲーム内容*

プレイヤーは生成された迷路にある赤の円を緑色のゴールに導きます。

操作方法は

Aキーが左移動

Dキーが右移動

Wキーが上移動

Sキーが下移動

スペースキーが迷路の再生成

また、右にあるコーナーで迷路の大きさを決められます。
