# **はじめに**

液晶をarduino dueというマイコンボードを使って液晶を制御してゲームができるようにしました。

# **概要**

僕は今までもarduinoを使って電子工作をしていたんですが、今まで作ってきたものはあまり遊んでもらえるようなものではなかったので今回は液晶を制御してゲームを作ってみようと思いました。

# **解説**
あまり複雑なことはできないのでゲームの内容は簡単なシューティングゲームにしました。仕組みは簡単に言うとゲームができるように液晶に表示を行わせるプログラムを高速でループさせてずっとゲームができる状態にしているという感じです。

# **感想**
今回ゲームを作るのは初めてでそこまで上手くはできませんでしたが、それでもなんとか形にすることができてよかったです。
