# **はじめに**

3DCG動画をblenderで作成しました。

# **概要**

海外でPoolRoomsと呼ばれている、無機質なプールが無限に広がる空間をblenderで作成し、そこを歩き回るようなアニメーション動画を作成しました。

# **解説**

展示したことはありませんでしたが3DCG動画を何度か作成したことはありました。

その時は技術が足りず、モデリングをブーリアンモディファイアを使用し、たくさんのオブジェクトを使っていたのでレンダリングに時間がかかり、物同士の繋ぎ目が不自然になってしまっていました。

今回はモデリング技術を身につけたので、かなり自然にクオリティの高い造形ができたと思います。
