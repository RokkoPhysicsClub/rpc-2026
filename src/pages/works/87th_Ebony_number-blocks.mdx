# NUMBER BLOCKS

**87期 EbonySerpent**

## はじめに

ネットでよく見るようなブロック崩しゲームを作ってみました。

## 概要

数字ブロックを崩していくブロック崩しゲームです。ただ崩すだけでなく、プレイ開始前に「Wizard」「Sniper」という2つのクラスから1つを選び、さらにパッシブ・ノーマル・スペシャルの3種類のスキルを組み合わせてから挑む、RPG的なビルド要素を取り入れました。

ノーマルスキルとスペシャルスキルは使うたびにエネルギーを消費する仕組みになっていて、通常発射だけでなくエネルギーを貯めて強力な一撃を放つか、といった駆け引きが生まれます。ブロックの種類も単純な数字ブロックだけでなく、破壊すると周囲にレーザーが走るブロック、爆発するブロック、特定の方向からしかダメージが通らないブロックなど全部で8種類用意しました。

ゲームモードも「ノーマル」（ターン制でブロックが一段ずつ迫る）、「プレッシャー」（リアルタイムで常にブロックが迫ってくる）、「カスタム」（シード値やブロックの出現率、速度などを自由に設定できる）の3種類を用意し、遊び方に幅を持たせています。

## 操作方法

### タイトル画面

- ゲーム開始ボタン：モード選択へ
- 設定ボタン：言語切替・操作説明

### プレイ中

- マウスカーソル：狙う方向を決める
- 左クリック：通常発射
- 右クリック：エネルギーを消費してノーマルスキル発射
- SPECIALボタン：スペシャルスキルの準備

## 解説

このゲームで最も苦労したのは、方向指定ブロックの「循環依存」の判定です。特定の方向からしかダメージを受け付けないブロックを配置する際、複数のブロック同士が互いに「相手の方を向いているせいでどちらも絶対に壊せない」という詰み状態を作ってしまう可能性があります。そこで、ブロックの依存関係を有向グラフとして構築し、深さ優先探索で閉路（サイクル）が生まれていないかを毎回チェックし、詰みが起きそうな場合は自動的に通常ブロックへ差し替える処理を組み込みました。

次に苦労したのは、スキル同士の組み合わせによる相互作用です。パッシブ・ノーマル・スペシャルは自由に組み合わせられるため、爆発と連鎖ダメージが同時に発生した場合の処理順や、オーラを付与された弾がさらに別の効果を受けた場合の扱いなど、組み合わせ数が膨れ上がる中で矛盾が起きないように一つ一つ条件分岐を積み重ねる必要がありました。

また、UIのカルーセル（スキル選択画面で横にスクロールしながら選ぶ部分）も工夫した点です。マウスホイールや矢印キーで選択位置を滑らかに補間させつつ、中央から離れたスキルほど縮小・透過させることで、選んでいる感覚を出すようにしました。

演出面では、クリティカル時の雷エフェクトや、スペシャルスキルの「Freeze」使用時に画面全体に雪の結晶が舞う演出など、パーティクル系のエフェクトを多数実装しました。ルール自体はシンプルなブロック崩しですが、ビルドを考える楽しさと、視覚的な派手さの両方を意識して作りました。
