# **注意**

これは他の作品とは違い、少し危険であるため、触らないでください。

# **はじめに**

今回、僕は中世ぐらいで使われていた投石機を小型で再現してみました。

# **材料**

部室にあったレゴを使って組み、おもりは金属球を2つ使いました。


# **作ろうとしたきっかけ**

僕はあまりプログラミングが得意でないので、何か目に見えるものを作ろうと思い、作りました。

# **反省点**

- どうしても、後ろ向きに球が飛んでいってしまう点や地面に叩きつけてしまう点

- レゴの強度が足りない点

などの問題が克服出来ませんでした。
